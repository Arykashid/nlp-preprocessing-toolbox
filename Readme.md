# NLP Text Preprocessing Toolbox

A simple Streamlit web app demonstrating core NLP preprocessing concepts from **Unit 1: Introduction to NLP**.

## Modules Included
1. **Tokenization** — word and sentence tokenization
2. **Stop Word Removal** — removes common English stop words
3. **Stemming & Lemmatization** — side-by-side comparison of both techniques
4. **Text Normalization** — lowercasing and punctuation removal
5. **Regular Expressions** — extract emails/numbers/dates, or run a custom regex pattern
6. **Minimum Edit Distance** — computes Levenshtein distance between two words, with optional DP table view

## Tech Stack
- Python
- Streamlit (UI)
- NLTK (NLP processing)
